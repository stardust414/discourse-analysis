# Discourse Analysis 3.3.1 多語版使用說明

這是 **Discourse Analysis 3.3.1 的多語本地化版本**，提供 English、简体中文、繁體中文及「跟隨系統」。產品名稱和應用內版本仍為 Discourse Analysis／3.3.1，不是上游新增的官方版本，也沒有重新品牌化。

本次正式交付包含 **Mac arm64（Apple Silicon／M 系列）**和 **Windows x64 Portable**。兩個版本共用相同專案格式；介面語言不改經文或使用者內容。

原作者、Bible source、profile 來源與版權署名均保留。原專案來源與使用條件請見[原 README](../../README.md)及倉庫原有版權／授權說明。本地化不表示取得原作者官方認可，也不把所有中文術語宣稱為各作者的官方中譯。

## 取得與開啟

正式檔案位於本專案的 `dist/final-zh-Hant/`：

| 平台 | 交付檔名 |
| --- | --- |
| Mac arm64 | `mac/Discourse Analysis-3.3.1-zh-CN-zh-Hant-arm64-mac.zip` |
| Windows x64 Portable | `windows/Discourse Analysis-3.3.1-zh-CN-zh-Hant-win-x64-portable.exe` |

兩個檔案均直接複製已實測的 T2 原檔，只更改外部檔名，內容完全相同。各平台資料夾內有 `SHA256SUMS.txt` 和交付紀錄；完整校驗值也見[最終交付報告](T3-繁體中文最終交付報告.md)。文件留在倉庫，不需要塞進應用包。

### Mac

1. 從可信的交付來源取得 ZIP，雙擊解壓，得到 `Discourse Analysis.app`。
2. 可以放入「應用程式」或你選擇的資料夾。如果已有同名版本，先保留舊應用及專案備份，確認新版本可用後再決定替換。
3. 雙擊應用。首次畫面可填寫姓名或略過，之後在設定中調整。

本包面向 arm64，不是 Intel Mac 套件。**目前沒有有效 Developer ID 簽名，也沒有 Apple notarization（公證）**。已在本機實際運行，但經網路下載或其他方式傳送後，macOS 仍可能提示無法驗證開發者。

若受到阻擋，先確認來源及校驗值，保留提示內容；可參考倉庫既有[macOS 安全開啟說明](../zh-CN/README-zh-CN.md#macos-签名和首次打开)，按系統針對單一應用提供的流程處理。不要全域關閉 Gatekeeper、停用 SIP 或關閉系統安全保護。若提示已知惡意軟體、檔案損壞、校驗值不符或受到管理政策限制，先停止並核對原因。

### Windows

1. 從可信的交付來源取得 Portable EXE，放入你要保留的位置。
2. 雙擊 EXE 啟動；這是 Portable，沒有另附 Setup 安裝程式。
3. 首次使用後，可在設定中選擇介面語言。開啟既有專案時，使用應用內的「開啟」。

這個精確 EXE 已由使用者複製到外部 Windows 電腦啟動並試用，未發現問題。測試電腦的 Windows 版本、CPU 和專項條件未記錄，因此不代表所有 Windows 版本或硬體均已認證。

**Windows 檔案未簽名，沒有 Authenticode。** 下載／第一次啟動時，系統或安全軟體可能顯示發行者或信譽提示；本次外部試用沒有專項記錄 SmartScreen／Defender 的行為。先核對可信來源與 SHA-256，保留提示並聯絡交付者，不要為了啟動而關閉 SmartScreen、Defender 或修改安全政策。

Portable 不代表所有本機偏好都存在 EXE 同一資料夾；語言等設定仍按應用既有的本機儲存方式處理。

## 切換介面語言

1. 開啟左側的「設定」（简体中文為「设置」，English 為 Settings）。
2. 找到「介面語言／界面语言／Interface language」。
3. 選擇「跟隨系統」、English、简体中文或繁體中文；選取後立即生效，不必重新載入經文，重啟也會記住選擇。

「跟隨系統」依第一優先系統語言判斷：明確 Hant 或 TW／HK／MO 使用繁體；明確 Hans 或 CN／SG／MY 使用簡體。明確 script 優先於地區，裸 `zh` 延續簡體；其他、不支援或無效語言使用 English。缺少翻譯時也回到 English，不會用簡體補繁體缺字。

語言只是本機介面偏好，不寫入專案或雲端資料，也不進入復原／重做歷史。

## 關係名稱與課堂對照

五套記號方案仍是 Josiah、BibleArc、Gurtner、Beale、Schreiner，沒有把它們強制統一。

關係選擇器空間足夠時顯示「中文短名＋目前方案的原英文簡稱／符號」。縮窄時先壓縮中文，極窄時只留下完整原記號。圖內的英文記號、星號、斜線、大小寫和顏色保持原樣，方便與原作者、英文教材及老師課件對照。

關係指南、提示和鍵盤焦點詳情提供完整名稱，例如：

- Schreiner：`理據 Ground（G）`
- Schreiner：`雙重理據 Double Ground（DG）`
- Josiah：`行動—目的 Action-Purpose（Ac / Pur*）`

Schreiner 繁體介面的 18 個關係名及分組參考使用者提供的正式繁體出版節選（書頁 123–124）；**雙重理據**另依使用者提供的授課課件，課件註明 Double Ground 為英文第二版新增。軟體定義文字不是全部取自該出版節選，其他方案的繁體譯名也不歸因於 Schreiner。詳見[術語來源說明](Schreiner-繁體術語來源與顯示規則.md)。

出版節選中的中文簡稱只作來源參考，不替換軟體原有 `S`、`G`、`BL`、`DG` 等記號。其他四套方案繼續使用通用繁體名稱。

搜尋同時接受簡體、繁體、English、原記號及關鍵詞。例如 Schreiner 的 Ground 可輸入「理據」「理由」「Ground」「G」；Double Ground 也能以舊通用詞「雙側理由」找到，主顯示仍是「雙重理據」。

## 開始分析與保存

1. 用既有英文經文格式輸入，例如 `John 1:1-5`，選擇譯本並按「載入經文」；也可以貼上自己的文字。
2. 在文字中放置游標，按 Enter 拆分行；按圓點建立括號，再選擇關係。按兩下通常用於選詞，不是拆分。
3. 按需要使用評論、回覆、經文主旨摘要、縮排結構圖及平行經文欄。
4. 用「儲存」保存 JSON，「另存新檔」建立另一份；用「開啟」讀取 JSON，或還原本軟體匯出且包含專案資料的 PNG／PDF。
5. 分享前確認內容。PNG／PDF 可以含可還原的完整專案資料，不只是畫面；評論、姓名、摘要也可能一併保存。

經文或雙欄圖較寬時，可平移／捲動、收合側欄或調整應用原有縮放。載入經文與雲端功能沿用原網路服務，服務不可用時不代表介面語言或專案格式有問題。

## 資料相容與不變的內容

Mac／Windows 共用 project schema 3，profile schema 1。切換介面語言不自動簡繁轉換 Scripture、命題、評論／回覆、摘要、使用者姓名、專案標題、自訂方案或自訂關係名稱。簡體專案在繁體介面開啟後，正文仍保持原簡體；切回 English 也不改內容。

專案 JSON 不增加 language、locale 或繁體旗標。自訂記號方案仍按原應用的本機設定及方案匯入／匯出方式處理；需要在另一部電腦使用時，按原功能另行匯出並載入方案檔，不假定它會隨一般專案 JSON 一併搬移。

- 本交付不包含獨立功能分支尚未整合的本機離線新標點和合本（CUNPS_LOCAL）；現有在線譯本來源與行為不變。

- English 專業名稱、英文記號、產品名、譯本名與使用者內容有意保留，不是漏譯。

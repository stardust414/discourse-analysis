## 必須繼承的定義與方向

| 概念 | 建議繁體說明／邊界 | 原 key |
| --- | --- | --- |
| 雙向支持 Bilateral | 中間命題作為根據，支持其前後兩邊。不能與 Double Ground 換方向。 | relationship.definition.bilateral |
| 雙側理由 Double Ground | 中央命題受到前後兩側理由的支持。 | relationship.definition.double-ground |
| 方式關係 Way-End | 說明一個行動以何種方式實行。對應 manner，不譯成方式—結果。 | relationship.definition.Way-End |
| 手段—目的 Means-End | 行動及其預期目的；不與 Way-End 合併。 | relationship.definition.Means-End |
| 選擇關係 Alternative | 來自同一處境的不同可能／選項；不表示形式邏輯上的排他二選一。 | relationship.definition.alternative |
| 意思—解釋 Idea-Explanation | 後一內容澄清前一內容的意思，可以解釋一個詞或整個命題。 | relationship.definition.idea-explanation |
| 逆接 Adversative | 保留 concessive／contrary-statement 性質，不把所有一般轉折歸入此類。 | relationship.definition.Adversative |

原軟體 English 定義與使用者審定中文在 Bilateral 的方向措辭並非逐字相同。此差異已在原 v1.1 記錄；繁體繼承人工審定語義，不藉重譯英文偷偷改回另一方向。English 原文仍須可發現，不冒稱繁體是各位作者的官方中譯。

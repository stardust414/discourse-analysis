本文件記錄使用者批准 T1 後的 T2 決定；T1 v0.1 文件與證據保留為歷史，不回寫其審核狀態。

## 語言及普通 UI

內部繁體代碼 zh-Hant，四種偏好 system／en／zh-CN／zh-Hant；新增 language.traditional，三語各 601 key。Follow System 明確 script 優先，未知／無效回 English；缺譯不回 zh-CN。

普通 UI 採使用者本輪批准詞表。與早期建議不同之處：**Redo 正式用「重做」**，不是「取消復原」。Comment 用評論，Highlight 用醒目標示；Undo 復原、Restore 還原、Reply 回覆、Copy 複製不混用。

模式名稱正式用縮排結構圖／括號檢視／平行經文欄／平行譯本／記號方案／經文主旨／經文主旨摘要。

## 通用 D01–D28 與 profile 特例

通用繁體採 [T1 專業表](繁體專業術語審核表-v0.1.md) 的 28 名稱；English、ID、縮寫與五套 92 行 raw profile 資料完全保留。雙向支持／雙側理由的支持方向分開；Way-End 不作結果；Alternative 不限定排他二選一；Idea-Explanation 後者澄清前者；Adversative 保留 contrary 性質。

**Schreiner zh-Hant 依追加決定覆蓋 19 個主顯示名稱及五個分組**，詳見 [來源與逐項表](Schreiner-繁體術語來源與顯示規則.md)。Double Ground 主顯示「雙重理據」，舊「雙側理由」只作通用詞與搜尋相容。通用 D 表不刪除，其他 profile、English、zh-CN 不受覆蓋影響。

## s.S0622 方向修正

使用者正式批准同時修正既有簡體句子。English、參數 ID、呼叫參數、取代邏輯與 undo 完全不變。

- zh-CN：`确定用 {oldTranslation} 替换当前 {newTranslation} 栏（包括所有编辑内容）？可按 Ctrl+Z 撤销。`
- zh-Hant：`確定以 {oldTranslation} 取代目前的 {newTranslation} 欄（包含所有編輯內容）？可按 Ctrl+Z 復原。`

目前 ESV、新選 NASB 的實際確認框已加入測試；取消仍保留原欄。

## 不轉換的範圍

經文、命題、評論／回覆、摘要、姓名、專案標題、自訂 profile／關係名、匯入資料全部原值。專案 schema 3、profile schema 1，偏好只存本機。沒有修改 Bible service、依賴或另外的 local-cuv 分支。

## 追加批准：七處英文語法單位參數例外

使用者正式回覆：「批准這 7 處語法單位例外，保留自然中文句式」。範圍僅限 s.S0017／s.S0026／s.S0029 的 verses、s.S0422／s.S0425 的 rows、confirm.deleteDependents 的 brackets、block.verses 的 unit。這些用固定中文單位表達，未刪資料參數；其他未知或省略參數仍需報錯。

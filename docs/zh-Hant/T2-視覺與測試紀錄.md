## 發現與處理

1. 繁體 UI 字體變數會影響繼承同一變數的 Greek 經文。已分離原有 script 字體栈，僅 UI 使用 TC／JhengHei 回退；Greek 和原文結構圖仍沿用原字體。沒有新增字體檔，Hebrew 原規則未改。
2. 最初新測試引用不存在的 toggleBlockBtn，已改為實際「其他檢視」選單。未刪減或放寬原有測試斷言。
3. 最初新恢復測試誤用只解析 JSON 的 importFileInput；而且未先清除原資料，可能誤判成功。已改為先載入不同的 sentinel 專案，再經真實「開啟檔案」入口分別還原 JSON／PNG／PDF，要求原資料完整回來。瀏覽器及 packaged Mac 均重新通過。這是驗證方法修正，沒有修改應用的讀檔行為。
4. 原版縮排結構圖會將 English 關係名轉小寫，例如 `理據 ground`。本輪沿用該既有行為；完整原 English Name 可在 Guide、selector title／ARIA／focus 詳情取得。不把這種既有顯示樣式當成新翻譯缺失。

本輪未觀察到阻塞使用的繁體按鈕截斷、文字重疊或 modal 溢出。小視窗＋150% 的經文／圖形需要平移及捲動，這是原工作區方式；未刪除內容或縮小字體掩蓋問題。全面雙平台排版與 Windows 系統 DPI 留 T3。

## Packaged Mac 實測

從測試 ZIP 解壓後啟動，app.isPackaged=true、arm64、3.3.1；20 項全部通過。[逐項結果](T2-evidence/mac-smoke.json)／[執行紀錄](T2-evidence/mac-smoke.log)。使用獨立 scratch userData，未改一般使用者設定。

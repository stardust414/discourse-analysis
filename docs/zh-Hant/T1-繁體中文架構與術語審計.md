## 5. 如何加入 zh-Hant

現有 en.js／zh-CN.js 是靜態 catalog；i18n.js 管理偏好、fallback、插值、DOM 綁定、即時刷新；relationships.js 為獨立顯示／搜尋層。新增靜態 js/i18n/zh-Hant.js，在核心初始化前載入，沿用同一 key 集和安全文字綁定。

目前允許值只有 system／en／zh-CN，需要擴充 zh-Hant。native-menu.cjs 亦只有兩份 catalog 與白名單，需要同步載入第三份。main.js／preload.js 已以一般 locale IPC 傳遞，預計只需驗證，不需重寫。

現有 selectorPresentation 只在 zh-CN 啟用緊湊雙語模式，應擴為兩種中文書寫系統共用規則；searchTerms／searchKeywords 現在只收 zh-CN，應共同索引兩份中文名稱、定義與關鍵詞，同時保留 English／profile 名稱／原縮寫。不要以大量語言分支重做架構。

## 6. Follow System 判別設計

內部唯一繁體選項用 zh-Hant，不用 zh-TW 作偏好值。建議保留目前「只依第一優先系統語言」的策略，不因使用者第二語言是中文而覆蓋第一語言。

| 判別順序 | 系統 locale | 解析結果 |
| --- | --- | --- |
| 先看明確 script | zh-Hant、zh-Hant-TW、zh-Hant-HK、zh-Hant-CN | zh-Hant |
| 先看明確 script | zh-Hans、zh-Hans-CN、zh-Hans-SG、zh-Hans-TW | zh-CN |
| 無 script 時看 region | zh-TW、zh-HK、zh-MO | zh-Hant |
| 無 script 時看 region | zh-CN、zh-SG、zh-MY | zh-CN |
| 延續現行裸 zh 行為 | zh | zh-CN |
| 其他／未知／無效 | en-US、fr-FR、ja-JP、zh-US、空值、無效值 | en |

明確 script 優先於 region，大小寫和底線輸入可正規化。建議以內建 Intl.Locale 讀取 language／script／region 並捕捉無效值，避免把 extension 字串誤當 script；不引入依賴。23 個來源現行結果與 T2 設計預期見 [locale 設計案例](T1-locale設計案例.json)。這是設計表，尚未修改或通過新的 production resolver 測試。

缺失／無效翻譯直接回退 English。**zh-Hant → zh-CN 的 fallback 不在設計中。**

## 7. localStorage 與資料邊界

沿用 biblebracket_language，允許值增加 zh-Hant 即可，不改儲存結構。偏好只留本機；不進專案 JSON、雲端專案或 undo/redo。儲存不可用時沿用目前僅本次工作階段生效的安全處理。

手動選單：Follow System／English／简体中文／繁體中文。簡體介面顯示「跟随系统／English／简体中文／繁體中文」；繁體介面顯示「跟隨系統／English／簡體中文／繁體中文」。切換不能覆寫輸入值、經文、評論、摘要、名稱、選區或草稿。

## 15. 建議繁體 UI vocabulary

設定、儲存、另存新檔、開啟、載入、匯入、匯出、下載、檔案、專案、搜尋、刪除、資料、預設、自訂。動作須按實際語義分開：復原／取消復原、還原、回覆、複製；追加不等同取代，開啟不等同載入，檔案不等同可編輯文件。

## 17. 28 類 Relationship 建議

| English | 建議繁體 | English | 建議繁體 |
| --- | --- | --- | --- |
| Series | 並列列舉 | Progression | 遞進 |
| Alternative | 選擇關係 | Both-And | 兩者並列 |
| Ground | 理由 | Inference | 推論 |
| Bilateral | 雙向支持 | Double Ground | 雙側理由 |
| Cause-Effect | 原因—結果 | Action-Result | 行動—結果 |
| Action-Purpose | 行動—目的 | Conditional | 條件 |
| Temporal | 時間 | Locative | 地點 |
| Action-Manner | 行動—方式 | Comparison | 比較 |
| Negative-Positive | 否定—肯定 | Idea-Explanation | 意思—解釋 |
| Question-Answer | 問題—回答 | General-Specific | 概括—具體 |
| Fact-Interpretation | 事實—詮釋 | Anticipation-Fulfillment | 預期—實現 |
| Concessive | 讓步 | Situation-Response | 處境—回應 |
| unspecified / ? | 未指定 | Way-End | 方式關係 |
| Means-End | 手段—目的 | Adversative | 逆接 |

完整顯示包含各 English 名稱；Way-End 不能改成方式—結果。雙向支持是中央支持兩側，雙側理由是中央受到兩側支持；選擇關係不限定排他二選一；意思—解釋保留「後者澄清前者的一詞或整個命題」；逆接保留 concessive／contrary-statement 性質。七項關鍵定義的繁體建議及其餘核心概念見 [專業審核表](繁體專業術語審核表-v0.1.md)。

- 28 名稱及 92 映射：raw ID／縮寫／星號／顏色／順序不變，profile 異名正確，自訂與使用者改名不翻譯。

## 5. Follow System

明確 script 優先：Hant→zh-Hant，Hans→zh-CN，即使地區衝突也以 script 為準。無 script：TW／HK／MO→zh-Hant；CN／SG／MY→zh-CN；裸 zh 延續 zh-CN。其他、不支援或無效值→English。大小寫、底線先安全正規化；使用內建 Intl.Locale，沒有新增依賴。

保留第一優先系統語言策略，不因次要語言是中文而覆蓋主要語言。單元測試涵蓋要求的所有 locale 與衝突／無效案例；瀏覽器另驗證 TW／HK／MO／Hans-TW。Mac 跟隨的是實際目前系統語言，未為測試修改系統設定。

## 6. Fallback

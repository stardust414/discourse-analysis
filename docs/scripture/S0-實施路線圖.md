## 3. S2：Online Chinese Scripture（凍結點一）

先解決 A/B edition / PD 權源 gate。選定 CUVS `cmn-cu89s / cmn_cus`、CUVT `cmn-cu89t / cmn_cut`，**不是 FHL unv，也不是任意同名 CUNP / 2011 Modern Punctuation**。如權源不能澄清，暫停這兩 entry 發布或另提明確授權 edition，不以換來源藏掉問題。

以 fetch(bible) 作優先外層 provider；核對 USX span 或 raw-source + span index，不能只按 txt[ch][verse]。必要時受控 eBible source adapter / 離線預處理，但不回引 local-cuv code。先 main passage，再獨立小增量做 parallel；parallel range / chapter / first split row / missing / replace undo 全通過才開。

CUVS / CUVT 各驗 66/1189、source spans / missing、Psalm119、3Jn15；parser 不吃 notes。包含 verse range 只查 span 第二節、superscription、script / divine-name variant。UI labels 三語、正文不跟隨 UI 簡繁轉換。project save/reopen / share / add 混段行為與 provenance 限制須明示。CNV/TCV 只有取得本 app 具體授權才加入，不讓它們拖住已授權版本。

network gate：正式允許 CDN / metadata host，Cloud GET/Origin/CORS + Chromium CSP + Electron file:// smoke；不要透過 disable webSecurity 解決。取得成功不能代替 license gate。E2E 主要 fixture，少量 live PD smoke 獨立運行。

驗收：既有全回歸 + CUV 主文操作鏈 / 三語 / 斷網 project reopen；parallel 未就緒則不開新中文 provider 的 parallel。凍結 Online schema/data contract、source version、attribution；人工批准後才 S3。

僅可下載已確定 Public Domain 或明確授權完整下載的 edition。UI download/update/delete、userData/main IPC、staging/manifest/hash/atomic version switch、resume/rollback、容量與損壞恢復；不得把後下載資料放 app.asar。local first、同版 online fallback；已有 project 不因更新 / 刪庫改變文字。

## 5. 一個版本同時 Online + Download？

推薦 **B：同一開發項目、兩個凍結點**。S1 是準備，S2 Online 凍結，S3 Offline 凍結。兩個凍結點可以最終放同一正式 Release，但不能在一次未凍結的大改中同時上線。

A 一次做完會把 parser / mapping、版權、filesystem、IPC、中斷恢復和 UI regression 混在一起，定位問題與回滾都難；現在尚有 edition 與 Cloud 網路 blocker，尤其不適合。C 兩個獨立 Release 亦合理：若 Offline 儲存 / 授權 / 平台測試延後，而 Online 已驗收，就分開發版；不要為追求同版本犧牲 gate。預設不預先承諾版本號或日期。

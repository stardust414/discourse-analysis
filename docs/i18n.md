# Internationalization (phase 3 foundation)

The app still uses classic browser scripts. No runtime package or frontend build
step was added. English is the complete baseline for all introduced message keys;
this phase intentionally localizes a representative UI subset, not the whole app.

## Files and boundaries

- `js/i18n/en.js`, `zh-CN.js`: flat message catalogs; strings or plural forms.
- `js/i18n/i18n.js`: locale resolution, local preference, safe interpolation,
  marked DOM bindings, templates and change subscriptions.
- `js/i18n/relationships.js`: display/search adapter for the approved v1.0 terms.
  `DA_PROFILES.getName()` continues to return the original data name.

The preference `biblebracket_language` stores `system`, `en`, or `zh-CN` in local
storage. It is not a document property, undo action or cloud setting. Electron
exposes only a read-only system-language query through its existing preload bridge.
The primary system locale is used: Hans/CN/SG/MY and plain `zh` select Simplified
Chinese; Hant and unsupported locales fall back to English. Browser language is
used if the native query is unavailable. Returning to `system` queries the OS again.

## Using messages

```js
DA_I18N.t('project.codeCopied', { code }); // plain text, never HTML
DA_UI.showTranslatedStatus('relationship.removed', { count }, 'success');
// A derived display value must also be resolved again when locale changes:
DA_UI.showTranslatedStatus('relationship.changed', () => ({
  label: DA_RELATIONSHIPS.getName(type)
}), 'success');
```

English plural messages use `{ one: '...', other: '...' }`. Chinese can use a
single complete sentence. Plural rules follow the actual fallback message's locale.
A missing Chinese entry falls back to English; a missing English entry returns the
non-empty safe text `Text unavailable`. Add an English entry for every new key.

```html
<button data-i18n-title="settings.tooltip">
  <svg><!-- existing icon --></svg>
  <span data-i18n="settings.open">Settings</span>
</button>
<input data-i18n-placeholder="passage.placeholder">
```

Supported markers: `data-i18n`, `data-i18n-title`, `data-i18n-placeholder`,
`data-i18n-aria-label`, and `data-i18n-data-placeholder`. Fixed parameters can use
`data-i18n-args` containing JSON. Prefer a marked text span when a control contains
icons or keyboard hints. Only explicit bindings are translated. Input values and
editable content are never replaced by text bindings.

`DA_I18N.apply(root)` supports DOM fragments, template contents and cloned
elements. A child-list observer applies bindings to newly inserted elements; it
does not inspect or replace arbitrary text. Live parameter providers use weak
references to DOM elements. `onChange()` returns an unsubscribe function.

## Relationship safety

Only recognized, unchanged builtin names are localized. Custom profiles, renamed
relationships and `cl_` labels remain verbatim. Profile IDs, type IDs, aliases,
abbreviations, stars, colors and ordering are not translated. Do not use the
display adapter to populate the notation editor's writable name inputs.

Search extends the existing index with approved Chinese names and help text while
preserving all original English names, abbreviations and keywords. Filtering waits
for IME composition to finish; Enter during composition does not select a result.

Chinese help for Bilateral and Way-End follows the human-reviewed v1.0 decisions.
The original English definitions remain unchanged as upstream baseline evidence.
Five unreviewed group headings and two cloud-toggle labels intentionally exercise
English fallback; this is not a claim of complete Chinese coverage.

## Regression checks

`npm run check` runs lint, type checks and all unit tests. `npm run test:e2e` runs
the original 30 English scenarios plus the new i18n scenarios. The original tests
explicitly seed English; their assertions are preserved. Native Mac validation
uses a separate `--user-data-dir` and the actual ZIP-extracted application.

Do not fix the original word-internal split/merge spacing behavior or change the
signing strategy as part of internationalization. See the Chinese phase 3 report
for results, artifact locations and the remaining phase 4 scope.

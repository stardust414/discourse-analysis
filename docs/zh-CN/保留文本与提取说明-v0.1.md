## 覆盖与方法

从 32 个应用 JavaScript 文件读取 3524 个原始字符串／模板；同时解析完整 index.html（含 template、title、placeholder、ARIA、data-placeholder）以及 CSS content。使用本机已有 Pygments 的 JavaScript 词法器和 Python 标准库 HTMLParser、ZIP／XML；没有安装新依赖。
去重候选初提取 803 条，人工补录 4 条被通用过滤规则误排的 Note 消息，以及 Bracket、Unknown 两个显示回退，最终 809 条。人工审读候选、直接回查源文件，并将 470 条实际文案分别放入普通清单和专业文案附录。其余是专业定义证据、保留项、内部内容或组合片段。
提取编号不是未来翻译键；同一条记录可能有多个使用位置。原文中的变量没有求值，不会读取 API 密钥、用户存储或远程账户。HTML 多段强调文本与原生字符串拼接在实施时须改成完整句，不能逐片翻译。
动态内容分类规则：用户文字、经文、书卷解析数据、项目名、评论、摘要、版本代码、缩写和符号不自动翻译。技术诊断日志不纳入普通界面翻译。第三方原始异常不逐句承诺中文化；已知错误边界另有拟译。
没有逐条提取第三方 vendored 库内部提示、Electron 自动生成的系统菜单或系统文件对话框按钮，因为它们不属于本仓库可枚举的文字源。后续需在 Electron 界面核对，再决定翻译自有菜单或适配原生界面。README 和自带 DOCX 用作背景和术语证据，不属于要自动翻译的应用界面；PDF 未另行逐页核对。
这是静态提取与人工复核清单，不宣称已经达到运行时零遗漏或完成视觉 QA；真实覆盖仍须在阶段 4 英文扫描、阶段 5 中英文运行验证中确认。

## 20 项 Mac smoke 与数据兼容

实际步骤覆盖：首次启动／Welcome、简体中文、English、跟随系统、网络载入 John 1:1–3 ESV、Enter 拆分、两处关系、选择器、中文搜索、英文／Ac/Pur 搜索、五套 profile 逐项切换、五套 Guide、Block Diagram、评论与回复、主旨摘要、网络 CUV 平行栏、自定义名称及 schema 边界、中文 JSON 保存后 English／中文打开、PNG 导出恢复、PDF 导出恢复、重启后中文与个人方案保留。若一个步骤含多个关联检查，原始记录保留其明细，不把统计数字替代用户操作。

本机原生首选语言为 `zh-Hans-CN`，Follow System 实际解析为 zh-CN。English 与手动中文也分别验证菜单及工具栏。未支持语言的 fallback 继续由 unit／E2E 的模拟 locale 场景验证，不改变本机系统语言。

项目完整序列化字段在各环节逐一比较，忽略的只有正常生成时间 `exportedAt`。`version` 保持 3，propositions、brackets／关系 IDs、评论／回复、主旨摘要、平行栏、姓名、自定义标签保持一致；项目没有新增 language／locale／profile 字段。个人 profile 的 schemaVersion 保持 1、ID 与名称原样，使用原本机存储机制独立核对。

进一步实际启动保留的原版 3.3.1 Mac 包，读取最终中文 JSON，并载入同一独立个人方案，再比较全部项目字段与方案。该原版包的 36 个源码文件也已与固定上游核对。这是实际同版本原版兼容验证，不只是比较字段名。

这些测试使用隔离的 `--user-data-dir`，没有访问用户日常资料，也没有发布或修改任何云端项目。真实经文由原有网络路径获取，未修改经文来源或正文。

# 阶段 2 人工审核修订报告 v1.0

日期：2026-11-03。已将翻译规范、专业术语表、专业相关界面文案、普通 UI 基准和五套 profile 的显示译名记录更新为 v1.0；v0.1 保留作历史记录。没有修改应用源码。

## 修改了哪些术语

D01–D28 全部按你的决定登记。相对原建议，名称实际变化的是：Alternative → 选择关系、Both-And → 两者并列、Bilateral → 双向支持、Double Ground → 双侧理由、Locative → 地点、Idea-Explanation → 意思—解释、Way-End → 方式关系 Way-End、Adversative → 逆接。其余关系名称按本次指令确认。

C01、C02、C08、C18、C20、C21 按你批准的名称固定；C19 明确为 dominance → 主次、dominant → 主导项、subordinate → 从属项。五套 profile 的 92 条对应记录全部同步，英文原名、符号、星号和内部键保持。

Way-End、Bilateral、Double Ground、Alternative、Idea-Explanation、Adversative 的帮助说明按你的指令修订。Bilateral 的原版英文定义仍作为证据原样保留，与人工审定的中文帮助分别标明；阶段 2.5 不会偷偷改掉原版定义。

## 是否有需要同步的界面句子

有。关系选择、悬停定义、关系指南、缩进结构图、评论目标标题、标签变更提示、跨越式关系选项和无障碍提示都依赖关系名称或方向；204 条专业相关界面文案已同步说明这些依赖。后续实施必须按当前 profile 调用审定名称，不能只改一张词表。

## 还有没有未决专业术语

本次点名的 28 项关系和 7 组 C 类术语没有未决改名。其余 24 组未逐项点名的 C 类用语沿用 v0.1 建议，未擅自登记为单项批准；具体编号见专业表。这个状态不影响下一步只验证英文原版的阶段 2.5。

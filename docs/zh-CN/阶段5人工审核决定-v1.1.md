# 阶段 5 人工审核决定 v1.1

2026-11-03，用户正式批准 C13–C17：并列关系、从属关系、以重述支持、以不同陈述支持、以相反陈述支持。当前版规范和术语表提升为 v1.1；v1.0 是历史审核资料。

新增显示约定：关系选择器默认优先“中文 + 当前 profile 原始简称／符号”；收窄时先压缩中文，极限空间只保留简称／符号。不得自行统一简称，不得截断简称。完整双语信息保留在关系指南、tooltip 和 hover／focus 详情中。

实施只影响显示，不改关系 ID、profile ID、缩写、星号、主次、颜色数据、顺序、映射或项目结构。其他既有术语决定与未逐项批准的通用词条状态不变。v1.0 的 Way-End、Bilateral／Double Ground、Alternative、Idea-Explanation 和 Adversative 语义约束继续有效。

用户另授权：实际验证“Double-click to split”提示，并可修正不准确的中英文 UI 文案；没有授权借此改变拆分功能或词内合并行为。

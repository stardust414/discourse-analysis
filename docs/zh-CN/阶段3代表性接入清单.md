# 阶段 3 代表性接入清单

本阶段只建立底层和覆盖各类渠道的样例，没有实施全部 470 条界面文案。以下 S 编号对应阶段 2 的提取清单；它们是审核追踪编号，不是业务 ID。

| 渠道 | 已接入的内容 | 审核记录／范围 |
| --- | --- | --- |
| 设置与语言偏好 | 项目设置标题、设置按钮、界面语言标签和三个选项、完成按钮 | S0716、S0752、S0792；语言选项为本次新增普通 UI |
| 顶部工具栏 | 载入经文、编辑文字、添加箭头、其他视图、撤销、重做 | S0021、S0728、S0730、S0732、S0678、S0735 |
| placeholder／tooltip | 经文范围输入例子、译本提示、设置说明、撤销提示 | S0655、S0652、S0715、S0733 |
| ARIA／data-placeholder | 界面语言选择器、关系筛选、主旨摘要的名称与占位 | S0545、S0739、S0742；没有改摘要正文 |
| 普通状态和错误 | 经文载入、Bolls 回退说明、载入失败且保留错误详情、清除成功 | S0019、S0018、S0020、S0011 |
| 变量与数量 | 复制项目代码、关系标签更改、删除一个或多个括号 | S0040、S0551、S0514、S0515 |
| 确认框 | 清除所有括号和格式的确认消息 | S0009；原确认／取消执行顺序保持，系统按钮仍由系统控制 |
| 关系选择器 | 标题、搜索框、悬停说明、关键词前缀、删除按钮、无结果提示 | S0535、S0544–S0546、S0556、S0504、S0562 |
| 专业关系显示 | 已审定的 28 个名称变体及相应中文帮助，区分各 profile | v1.0 的 D01–D28；缩写、星号、颜色、内部 ID 保持 |
| 关系指南 | 标题、表头、按当前 profile 解析的名称和定义；打开时和切换语言时更新 | S0468、S0699、S0793–S0797 |
| profile 相关界面 | 记号方案标签、当前方案指示、五套内置关系的独立显示 | S0754、S0736、S0737；高级编辑输入框仍显示原始名称，避免写回译名 |
| 动态生成菜单 | PNG、PDF、复制图片、项目 JSON 下载和复制菜单 | S0565–S0569；云同步开关的两个 key 保留英文回退 |
| 评论模板及克隆 | 编辑、删除、保存、取消、关闭、添加评论、回复输入及发送提示 | S0798–S0802、S0379、S0414、S0415；已写和未发送评论原样保留 |

English 字典有 125 个 key，zh-CN 有 118 个；这是本阶段消息键数量，不能当作对 470 条来源记录的覆盖率。

7 个仅有英文基准的 key 是有意保留的回退样例：5 个未逐项审定的关系分组标题，以及两个云同步开关标签。未知 key 返回非空的英文安全提示，不出现 undefined 或空白按钮。

未标记的菜单、帮助、提示、原生应用菜单和其他文字仍按原版显示。全面接入、英文遗漏扫描及更广泛的长文本布局检查留到阶段 4／5；没有为了本阶段样例顺带完成全软件中文化。

# Discourse Analysis 简体中文使用说明

这是 **Discourse Analysis 3.3.1 的简体中文本地化版本**，产品名仍为 Discourse Analysis。基于原项目固定源码 `98da0241c38eef936be0f06cf736aa607dda0b62`，保留原作者、译本来源和记号方案的署名。它不是上游发布的新官方版本，也不代表各位作者授权的“官方中译”。

原项目：[josiahhoi/discourse-analysis](https://github.com/josiahhoi/discourse-analysis)。原 README 与版权说明保留在[仓库 README](../../README.md)。软件原许可为 MIT；ESV 经文版权归 Crossway，SBLGNT 归 SBL／Logos，原项目所列来源和使用条件继续适用。其他译本、profile 和页脚来源署名不变。本地化没有重新品牌化或取得经文再授权。

## 中文版包含什么

- English、简体中文和跟随系统，可即时切换，本机记住选择。
- 主界面、设置、帮助、提示、菜单及无障碍名称的中文显示。
- 五套记号方案：Josiah、BibleArc、Gurtner、Beale、Schreiner。
- 中英文专业名称、中文／英文／原简称关系搜索，以及完整的关系指南。
- 英文简称、符号、星号和图内记号保留，便于课堂和教材对照。
- 浅色／深色模式，原有缩放功能；宽图表可以横向滚动。

## 如何打开 Mac 版本

本次正式交付面向 Apple Silicon（M 系列芯片）的 Mac。文件名为：

`Discourse Analysis-3.3.1-zh-CN-arm64-mac.zip`

1. 从你信任的本项目交付来源取得 ZIP，必要时核对[最终交付报告](阶段6最终交付报告.md)里的 SHA-256。
2. 双击 ZIP 解压，得到 `Discourse Analysis.app`。
3. 可将应用拖入“应用程序”文件夹；若已有同名版本，先保留旧版和项目文件，确认后再决定替换。
4. 双击应用打开。首次使用可填写姓名或跳过；不要把姓名当作云端账号或安全凭据。

应用 ZIP 只包含正常应用包，不含测试项目、浏览器缓存或测试用户数据。文档留在仓库，不需要放入应用内部。

## macOS 签名和首次打开

**当前构建没有有效 Developer ID 签名，也没有 Apple notarization（公证）。** 本机已从最终 ZIP 解压运行验证，但网络下载、邮件或其他传输方式可能触发 Gatekeeper，不能保证其他 Mac 会直接双击打开。

确认文件确实来自本项目可信交付来源、校验值一致后，可以按系统支持的方式处理单个应用：

- 在支持该方式的 macOS 上，在 Finder 中右键或按住 Control 点击应用，选“打开”，再确认。
- 若仍被拦截，先尝试打开一次，然后到“系统设置 → 隐私与安全性”，查看该应用对应的提示，选择“仍要打开”，并按系统要求确认。不同 macOS 版本的名称和入口可能略有差别。

这些步骤仅对你确认可信的这一个应用作出打开决定，不要求关闭 Gatekeeper、SIP 或任何全局安全功能。若系统报告已知恶意软件、文件损坏、校验不一致或单位管理策略限制，应停止并联系交付者，不要反复尝试绕过。正常安装不需要终端命令或移除 quarantine 属性。

Apple 的说明：[在 Mac 上安全地打开 App](https://support.apple.com/en-gb/102445)。将来若要面向公众正式分发，应另行使用交付者自己的 Apple Developer Program 账号处理签名和公证；本包尚未完成这一步。

## 如何切换语言

1. 点击左侧“设置”（English 模式下是 Settings）。
2. 在“界面语言 / Interface language”中选择：
   - **跟随系统 / Follow System**：默认选项。系统首选语言为受支持的简体中文 locale 时用简体中文，其他未支持语言用 English。
   - **English**：始终使用英文界面。
   - **简体中文**：始终使用简体中文界面。
3. 关闭设置。界面即时更新，不需要重新载入经文；重启后仍记住选择。

如果系统使用繁体中文，当前版本回退 English；本次没有增加繁体中文。极少数情况下本机存储不可用，选择仍可在当前会话使用，但可能无法跨重启保存。

## 专业关系怎样显示

关系选择器默认显示“中文 + 当前记号方案的原始英文简称／符号”。空间不足时先缩短中文显示，极窄时只显示完整简称。不会为了保留中文而把简称截断成无法识别的省略号。

完整名称可在关系指南、tooltip 和悬停／键盘焦点详情中查看，形式为“中文名称 English Name（当前方案简称／符号）”。例如 Josiah 的 `行动—目的 Action-Purpose（Ac / Pur*）`。星号、空格、大小写及斜线都来自当前方案原值，不是新增装饰。

不同方案不强行统一。例如 Gurtner 的 Way-End、Means-End 按该方案分别显示；Bilateral／双向支持与 Double Ground／双侧理由也分别解释。这样可以直接对应英文教材、老师课件及课堂简称。方案名和用户自定义名称保留原文。

审定译名见[中文界面翻译规范 v1.1](中文界面翻译规范-v1.1.md)与[专业术语审核表 v1.1](专业术语审核表-v1.1.md)。

## 开始一次分析

1. 选择译本，以现有英文引用格式输入，例如 `John 1:1-5`，点击“载入经文”。联网来源不可用时也可粘贴自己的文本。
2. 普通分析状态下，在文字中定位光标，按 Enter 拆分行。双击通常是选词，不是拆分。
3. 点击两行圆点建立括号，在选择器中搜索“理由”、`Ground` 或当前方案简称。可在设置中切换记号方案，并打开“关系指南”查看定义。
4. 按需使用“其他视图”中的缩进结构图和平行经文栏，添加评论及经文主旨摘要。
5. 使用“保存”保存 JSON，“另存为”建立另一份文件；“打开”可恢复 JSON，以及本软件带项目数据的 PNG／PDF。
6. “导出”可生成 PNG／PDF。它们可能包含可恢复的完整项目数据，包括评论、姓名和摘要；分享前先确认其中哪些内容适合分享，不要把导出图片当作已去除项目数据的匿名图片。

平行经文按节对齐：一节拆成多行后，译文只在该节首行载入，续行初始为空，可以编辑。较宽双栏图需要横向滚动，也可使用原有缩放或收起侧栏查看全貌。

## 数据兼容

切换语言只改变界面显示。本机语言偏好不进入项目 JSON、不写入云端项目，也不成为撤销历史。

项目版本、经文、命题、括号、关系 IDs、评论、摘要、平行栏、姓名和自定义关系保持原值。记号方案与自定义方案继续使用原版的本机设置、方案导入／导出机制；本地化没有把本机方案强行加入项目 JSON。需要在另一台机器使用个人方案时，按原应用功能另行导出和载入方案文件。

最终验证确认中文保存的项目可在 English 界面打开、再切回中文，并由固定原版 3.3.1 的数据读取流程读取。不要据此推断所有未知的旧版／未来版本都兼容。项目文件仍应定期备份。

## 已知限制

- 原版词内拆分后再合并可能插入空格；本地化保留该行为。
- 无有效 Developer ID 签名／公证；本机能运行不代表所有下载后的 Mac 都不会弹出检查。
- 部分系统文件选择器、系统菜单及第三方技术错误的语言由系统或外部服务决定。
- Windows 不是本次主要交付目标，没有本阶段 Windows 实机认证。
- 不支持新增的中文书卷名输入，继续使用 `John 1:1-5` 等程序现有格式。
- 英文专业名称、简称、产品名、译本名和用户内容有意保留，不是漏译。
- 经文载入和云功能依赖原有网络服务；本阶段没有扩展云功能或对云端生产数据进行验证写入。
- 没有完成所有输入法、所有 macOS 版本或完整屏幕阅读器认证。

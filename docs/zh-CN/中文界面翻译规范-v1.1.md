## 紧凑选择器

本软件服务于使用英文术语、课件和简称的学习场景。中文帮助理解，当前 profile 的英文简称／符号必须可辨认。

1. 空间足够：中文名称的紧凑显示 + 当前 profile 原始简称／符号。
2. 空间较紧：先压缩中文，保留完整英文简称／符号。
3. 极限空间：仅在视觉上显示英文简称／符号；完整双语名称仍作为按钮无障碍名称、tooltip 和详情。

简称直接读取 `DA_PROFILES.getAbbr(type)`，保留其大小写、空格、斜线、星号和符号。不能用用户举例中的 G、Bl、Ac/Pur 去统一数据中的 `* / G`、`BL`、`Ac / Pur*`，也不能自行从一个 profile 推断另一套的写法。自定义方案、自定义关系和用户改过的名称保持原文，不替用户起中文简称。

按钮中把中文与简称分成独立显示区域，简称不使用省略号、不压缩成零宽、不为保留中文而隐藏。中文可折行、压缩或隐藏；搜索输入、当前选项和键盘焦点保持。支持产品已有的手动调整选择器尺寸，并随窗口变化限制到可操作范围内。

## 完整双语显示

tooltip、hover／focus 详情采用：

```text
中文名称 English Name（当前 profile 原始简称／符号）
```

例如 Josiah 的完整显示为“行动—目的 Action-Purpose（Ac / Pur*）”；Gurtner／Beale 对应“手段—目的 Means-End（M / Ed*）”。这些星号来自各 profile 原值，不是额外添加的显示装饰。

关系指南继续分别显示完整双语名称、简称、关键词和定义；名称 tooltip 也提供完整对应。不能把双语全称塞进图内标签，图内原记号保持原状。Way-End、Means-End、Bilateral、Double Ground、Concessive／Adversative 等继续按当前 profile 和 v1.0 的审定语义分别处理。

## 沿用的边界与文体

- English 是完整基准语言；缺失中文时安全回退英文。生产字典不为了测试回退而故意留下已批准文案的空缺。
- 简体中文只用于显示。本机偏好、项目数据、云端数据和撤销历史的边界不变。
- 保存／另存为、打开／载入／导入、导出／下载、追加／替换、取消／忽略／放弃更改、评论／回复按实际动作区分。
- 按钮简短、状态自然、确认框说明后果。中文完整句用中文标点；变量、代码、URL、文件名和经文范围原样填入完整模板。
- 不翻译经文、评论、摘要、姓名、项目标题、自定义名称、IDs、schema、版本字段、译本代码、图内记号或嵌入项目数据。
- 不新增分发字体。使用系统中文 fallback；不以缩小定义或改写原文来掩盖布局问题，不改变希腊文、希伯来文及 RTL 数据。

## 上游提示的实测修订

阶段 5 在原有普通编辑状态实测：双击只选中词语、不拆分；在光标处按 Enter 拆分。因此来源 S0031 的“Double-click to split…”属于原版 UI 提示错误，按用户本阶段授权同步修正英文和中文。修订只改提示，不改拆分／合并行为。其他输入模式另按其现有说明，不把文字编辑模式的原生 Enter 换行混同为命题拆分。

当前审计与验证结果见《残留英文审计》《阶段 5 报告》和《阶段 5 视觉检查记录》。

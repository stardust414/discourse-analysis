浏览器矩阵逐组检查主工具栏、设置、表单、五套指南、关系选择器、简称不截断、焦点及选中状态、Block 标签。真实 Mac 矩阵检查最小／默认／较宽窗口、页面边界和选择器，真实工作流补足内容编辑、保存恢复、导出和重启。详细记录：[浏览器矩阵](阶段5验证证据/浏览器矩阵.json)、[Mac 工作流与矩阵](阶段5验证证据/native-result.json)。不是每个界面的每种状态都穷举 70 次。另用应用原有 75% 档并收起侧栏，补拍真实双栏全貌；100% 编辑截图保留横向滚动后的实际视野，不以截图裁切冒充适应窗口。

## 发现的问题、修复与复查

| 问题 | 修复范围 | 结果与证据 |
| --- | --- | --- |
| 原选择器按钮双语全称拥挤，不利于课堂简称对应 | 独立中文／原始简称区域；按容器宽度渐进压缩中文，简称不省略 | 五套共 92 项原值核对，40 组浏览器及 30 组 Mac 组合通过；默认／380／320 截图见上 |
| 英文关系词只在鼠标悬停时容易查到 | 聚焦提供同一完整双语详情；保留 title 与完整 ARIA 名称 | 键盘聚焦、切换语言、IME 测试通过 |
| 专业分组五项仍为英文 | 按 v1.1 正式批准接入，原词保留 tooltip 对照 | 五套指南及选择器检查通过；故意 fallback 为 0 |
| 深色云方案字段、身份字段和加入项目代码框仍有默认白底 | 仅补充相关输入的背景／文字／边框主题样式，合理最小宽度 | [修复前设置](阶段5验证证据/BEFORE-dark-settings.png) 与修复后设置／云入口截图；DOM 色值与实际包复核 |
| 长定义、双语名称、设置说明在窄窗口阅读拥挤 | 合理换行、可滚动 modal、表格列宽、行高、padding，保留定义字号和原内容 | 40 组矩阵全部通过；指南定义至少正常 15px 显示，未删定义 |
| 横向查看长画布后顶部操作栏会移出可见区 | 仅让工作区 header 在横向滚动时保持可达，截图导出时恢复普通流 | 窄窗、Greek／Hebrew、真实项目复核；左右横向滚动 PNG 宽度一致，导出后 zoom 与 live header 状态恢复 |
| 深色状态提示、弱对比文字和键盘焦点不够清楚 | 主题色、错误提示宽高、focus-visible、选择器主题前景与原关系边框色 | 浅／深主题、长错误、聚焦检查通过，图内关系颜色逻辑未改 |
| SVG 控件打开弹窗后焦点不能正确返回 | 焦点恢复同时识别 SVGElement；弹窗标题关联及图标按钮命名补齐 | Esc 关闭回到原关系控件／设置按钮，语言切换保留草稿 |
| Block 原文方向及双语长标签 | 逻辑方向缩进、文本自动方向、正常换行 | Greek／Hebrew 原样，RTL 和中文平行栏测试通过 |
| Double-click 导入提示与实际不符 | 只修正中英文提示为定位光标后 Enter 拆分，登记上游文案修正 | 双击选词、行数不变；Enter 拆分；英文／中文浏览器及 Mac 实测一致 |
| 拆分后的平行栏续行为空可能令人误以为丢失 | 中英文帮助明确每节只载入到首行、续行初始为空且可编辑 | 原分配函数及原 unit test 不变，实际 CUV 数据按原规则核对 |
